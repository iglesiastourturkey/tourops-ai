Build a production-ready MVP web application called **TourOps AI** for travel agencies.

The application should help travel agency employees create tour packages, calculate costs, prepare customer quotations, and track operational tasks.

## Main Goal

Create a modern AI-powered travel planning and operations platform that converts customer requests into structured tour proposals.

The primary users are:

* Travel agency product planners
* Tour operation specialists
* Sales representatives
* Incoming tourism agencies
* Small and medium-sized travel agencies

The first version should focus on destinations around Kuşadası, İzmir, Efes, Şirince, Pamukkale, Didim, Priene, Milet, Bodrum, and nearby areas, but the architecture must support adding any destination later.

## Technology Stack

Use:

* Next.js with TypeScript
* App Router
* Tailwind CSS
* shadcn/ui
* Supabase for database and authentication
* OpenAI API or Gemini API for AI-generated content
* React Hook Form
* Zod validation
* Recharts for dashboard charts
* React PDF or another reliable PDF library
* Mapbox or Google Maps for route visualization

Create a clean project structure and reusable components.

## AI Integration Rules

Create a provider abstraction so OpenAI or Gemini can be selected through environment variables.

The AI response must use structured JSON.

Validate all AI responses with Zod.

Never directly save an AI result without showing an editable preview.

When no AI API key is available, use realistic mock responses so the application still works in demo mode.

## Environment Variables

Create an `.env.example` file containing:

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
AI_PROVIDER=
OPENAI_API_KEY=
GEMINI_API_KEY=
NEXT_PUBLIC_MAPBOX_TOKEN=

Do not include real credentials.
