Implement Sprint 7.2 — Enterprise Administration (Role Permission Matrix + System Control)

Goal:
Replace hardcoded role checks with a configurable permission matrix managed by the super_admin while preserving the existing RBAC hierarchy.

This is the final enterprise administration sprint before production deployment.

Priorities:

- Production stability
- Enterprise security
- Permission-based authorization
- Zero breaking changes
- No business logic refactoring

==========================================================
1. SYSTEM CONTROL
==========================================================

Create:

/system-control

Visible only to super_admin.

Features:

System Mode:

🟢 Active

🟡 Maintenance

🔵 Read Only

🔴 Disabled

Behavior:

Active
- normal operation

Maintenance
- only super_admin
- optionally selected admin users
- everyone else sees a Turkish maintenance page

Read Only

- viewing allowed
- POST
- PUT
- PATCH
- DELETE
- APPROVE
- EXPORT WRITE
blocked

Disabled

only super_admin can enter

Everyone else:

"Sistem geçici olarak hizmet dışıdır."

Requirements:

- confirmation dialog
- maintenance message
- optional start/end time
- audit log
- changedBy
- changedAt

Super Admin must NEVER lock himself out.
