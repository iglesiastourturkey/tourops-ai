---
name: tourpilot-commit-style
description: TourPilot repo'suna commit yaparken kullanılacak format ve kurallar. Herhangi bir git commit hazırlarken kullan.
---

Commit mesajı formatı: "tip: kısa açıklama" (fix:, feat:, docs:, chore:)
Asla .env dosyalarını veya secret içeren dosyaları commit etme.
Commit öncesi git diff'i özetleyip kullanıcıdan onay iste.
